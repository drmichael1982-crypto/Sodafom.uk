Sodafom 177 Child Tutor

Purpose:
A child-facing Sodafom / Ask Archie screen that can sit over the working 797-style brain without showing private 797 admin or programming controls to children.

How it works:
1. Keep private 797 separate.
2. Run the 797 brain/service underneath.
3. Open the 177 child tutor screen.
4. The child sees Sodafom / Ask Archie, not 797.
5. One-to-one conversation is sent to the local 797 route: http://localhost:7970/api/v1/chat
6. If the local brain is not running, the page falls back to built-in starter lessons.

Included child sections:
- Reading
- Maths
- Spelling
- Science
- History
- Geography
- Knowledge Quiz / Games

Child safety rules:
- No visible 797 wording on the child screen.
- No programming panels.
- No admin controls.
- No model dropdowns.
- No worker controls.
- Responses must stay in child tutor mode for ages 5 to 12.

Hard drive use:
Copy this folder onto the 1 TB SSD, open index.html in Chrome or Edge, and run the 797 brain locally when full one-to-one responses are needed.
